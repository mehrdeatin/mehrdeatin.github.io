メイドアイティシュの群像 — Claude引き継ぎ資料

このZIPを見て、既存ファイルの文章と画像まわりを整理した。

今回反映済み
- HOMEの抽象的な導入を、世界・時間軸・ネモフィラリバーシに直接触れる短文へ変更。
- ネモフィラリバーシのsummaryを、ルーン→複数視点→ソリシア→ルーンという群像劇の構造に変更。
- 今日の依頼は猫さがしのsummaryを、猫探しの依頼から始まる50年後の話として具体化。
- ルーンのsummaryを「知識はあるが経験がない」という設定を軸に整理。
- キービジュアル／キャラクター画像をbackground-imageだけでなくimg要素で出す構造に変更。front matterのkey_visual / portraitを変更すれば画像を差し替えられる。
- alt属性とloading属性を追加。

文章編集の基準
- 抽象的な一般論、空疎な比喩、きれいにまとめるだけの結論を削る。
- 具体的な固有名詞・設定・ユーザー本人の言葉を優先する。
- 一文を長くしすぎず、説明を詰め込むより事実を置く。
- Vivyやガンダム 水星の魔女の公式サイトを参考にする場合も、特定作品の文章を模倣せず「短い事実提示」「余白」「情報を読み進めたくなる断片提示」という構成上の特徴だけ参考にする。
- ユーザーが自分で作成中のMarkdown本文を新規生成しない。

まだユーザー側で実画像のファイル名が確定していないため、以下は現状のfront matter指定を維持している。
- _works/* の key_visual
- _characters/* の portrait
実ファイルは assets/images/.../originals/ に入れる前提。

要確認
- GitHub Pagesの実URLを _config.yml の url に設定する。
- _config.yml に collections.chapters と defaults.type=chapters の重複定義がある。動作上ただちに問題になるとは限らないが、整理するなら一度ビルド確認してから行う。
- 画像最適化スクリプトが想定する originals/optimized の実際の入出力と、front matterの.jpg指定が一致するかをClaude側で確認する。
- 世界観／時系列ページに新しい画像欄を増やすかは、実際に入れたい画像が決まってから判断する。現時点では画像欄を闇雲に増やしていない。
